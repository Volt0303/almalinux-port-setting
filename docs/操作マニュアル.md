# 6ポートLAN IPアドレス自動設定・照合ツール 簡易操作マニュアル

対象OS: AlmaLinux 9.7 / 9.8　　対象: 6ポートLAN搭載産業用PC

---

## 1. 事前準備（初回・機種ごとに1回）

### 1-1. 量産機へ配置するもの

量産機（出荷する実機）へ配置するのは **`dist/` フォルダ一式** と
**`setup_desktop.sh`** の2つです（Pythonソースは不要）。

作業用フォルダは任意の場所で構いません（例: `~/PortSetting/`）。
**インストール先は `setup_desktop.sh` が自動的に `/opt/ipset/` へ配置します。**
（`~/ipset/` などへ手動配置する必要はありません。）

### 1-2. GUI用パッケージの導入（量産機で1回）

```
sudo dnf install -y google-noto-sans-cjk-jp-fonts
```
- **日本語フォントは必須**です（未導入だと画面の文字が □□□ になります）。
- `dist/` の実行ファイル（ビルド版）を使う場合、**Python や tkinter の導入は不要**です
  （実行ファイルに同梱されています）。
- Pythonソースから直接実行する場合のみ `sudo dnf install -y python3-tkinter` が必要です。

### 1-3. ポート対応表（config）の作成

**ポート対応表 `config/config_*.ini`** を、その機種の実際のインターフェース名に
合わせて用意します。確認用コマンド:
```
python3 tools/inventory.py
```
出力の `[port_map]` を、物理ラベル LAN1〜LAN6 の並びに合わせて保存します。
- Intel検証機 … `config/config_intel.ini`
- AMD量産機　 … `config/config_amd.ini`

（どの物理ポートがどれか分からない場合は `sudo ethtool -p enpXsY 10` で
該当ポートのLEDが点滅します。）

> **重要**: インターフェース名は**ボード機種ごとに異なります**。Intel機とAMD機で
> 同じ config を流用しないでください。

### 1-4. インストール（デスクトップ登録）

```
sudo bash setup_desktop.sh
```
これにより `/opt/ipset/` への配置、アイコン登録、管理者権限の設定が行われます。

## 2. GUIでの操作手順（通常作業）

1. ツールを起動します。
   画面左上の **「アクティビティ」** →「アプリケーションを表示する」→
   検索窓に **「LAN」** と入力 → 表示された **「LAN IP設定ツール」** をクリック。
   ```
   # （参考）コマンドから起動する場合
   /opt/ipset/launch_gui.sh
   ```
2. **［参照...］** で顧客支給の設定ファイル（CSV / Excel）を選びます。
3. **対象シリアル** を指定します。**一部を入力すると候補が表示される**ので、
   目的のシリアルをクリックして選びます（例：「199」と入力→該当シリアルが候補表示）。
4. 画面中央に **設定内容（期待値）** が LAN1〜LAN6 分表示されます。内容を確認します。
5. まず **「ドライラン（変更しない）」に✓を入れたまま**［設定開始］を押し、
   実行される内容（コマンド）を確認します。
6. 問題なければ **✓を外して**［設定開始］を押します。確認ダイアログで「はい」。
7. **設定結果** に各ポートの判定が表示されます。
   - **緑 = OK**（期待値どおり設定・照合できた）
   - **赤 = NG**（不一致・失敗）
8. 画面下部に **結果（PASS / FAIL）とログ保存先** が表示されます。
   ログは **デスクトップの `result.csv`** に保存されます。
9. 作業終了時、ウィンドウ右上の **×** を押すと、出荷前クリーニング用に
   **本ツールの削除（アンインストール）** を確認するダイアログが表示されます。
   - **「はい」**：ツールを端末から削除して終了（ログは既定で残ります）
   - **「いいえ」**：削除せず終了　　**「キャンセル」**：終了しません
   - ※ 本適用（設定＋ログ出力）を行った後のみ表示されます。ドライランのみの場合は
     通常どおり終了します。

## 3. コマンド（SSH / GUIが使えない場合）

```
# 内容確認のみ（変更しない）
python3 -m ipset.cli 設定ファイル.csv --serial シリアル番号

# 実際に設定を適用（管理者権限が必要）
sudo python3 -m ipset.cli 設定ファイル.csv --serial シリアル番号 --commit

# ファイル内のシリアル一覧を表示
python3 -m ipset.cli 設定ファイル.csv --list
```
終了コード: `0 = 全ポートOK`、`1 = NGあり`。

---

## 4. 結果の見方とNG時の対処

| 表示 | 意味 | 対処 |
|---|---|---|
| OK | 設定・照合成功 | 対応不要 |
| IP mismatch | 設定値と実際値が不一致 | 支給データ・配線を確認し再実行 |
| interface not found | 対象ポートが見つからない | ケーブル/カード装着、`config` の対応表を確認 |
| invalid data | 支給ファイルの値が不正 | 該当行のIP/マスクを確認 |

- **NGが出たら、まずドライランで期待値と実行コマンドを確認**してください。
- 起動時に「duplicate IP」警告が出た場合、支給データ内でIPが重複しています
  （支給元へ確認）。

---

## 5. ログ

- 実行結果は **デスクトップの `result.csv`** に追記保存されます（Excelで開けます）。
  （CLIの既定は `logs/result.csv`。`--log` で変更可）
- 列: 日時 / シリアル / LAN / IP / サブネット / ゲートウェイ / DNS / 実際値 / 結果 / エラー。
- 検査記録（トレーサビリティ）として保管してください。

---

## 6. 注意事項

- 実際の設定適用（`--commit` / GUIの本適用）には **管理者権限（sudo）** が必要です。
- `config/*.ini` は **機種ごと** に用意します（Intel検証機とAMD量産機で
  インターフェース名が異なるため）。
- 本ツールは IPv4 固定設定・6ポートを対象とします（IPv6等は対象外）。
