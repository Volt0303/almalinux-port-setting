# 検収チェックリスト（受入基準 仕様書16章）

対象機で下記を上から順に実施。各項目の「合格条件」を満たせば検収完了。

## Phase 1 — Intel検証機

### A. 事前準備
- [ ] ツール一式を配置し、`python3 --version` が 3.9 系であることを確認
- [ ] （GUI使用時）`sudo dnf install -y python3-tkinter`
- [ ] 実インターフェース取得: `python3 tools/inventory.py`
      → 出力の `[port_map]` を物理LAN1〜6に合わせ `config/config_intel.ini` に保存
- [ ] 物理ポート確認（任意）: `sudo ethtool -p <ifname> 10` でLED点滅を確認

### B. 検収項目（仕様書16章）

| # | 項目 | コマンド | 合格条件 |
|---|------|----------|----------|
| 1 | Excel/CSV読込 | `python3 -m ipset.cli 支給ファイル --list` | シリアル一覧が表示される |
| 2 | 期待値表示（変更なし） | `python3 -m ipset.cli 支給ファイル --serial <SN>` | LAN1〜6の設定内容とnmcliコマンドが表示 |
| 3 | 6ポート設定適用 | `sudo python3 -m ipset.cli 支給ファイル --serial <SN> --commit` | 全ポートに適用が実行される |
| 4 | 読み戻し・照合 | （上記に含む） | 実際値が読み戻され期待値と比較される |
| 5 | OK/NG表示 | （上記出力） | `Result: PASS (OK=6 NG=0)` |
| 6 | CSVログ保存 | `cat logs/result.csv` | 日時/SN/LAN/IP/…/結果 が追記されている |
| 7 | 終了コード | `echo $?`（commit直後） | PASS時 `0` |

### B-2. 追加機能の検収（GUI・生産性/出荷対応）

対象機のGUIで実施。

| # | 項目 | 操作 | 合格条件 |
|---|------|------|----------|
| 8 | シリアル絞り込み入力 | 対象シリアル欄にシリアルの一部を入力（例「199」） | 該当シリアルが候補表示され、クリックで選択できる |
| 9 | ログのデスクトップ保存 | 本適用（ドライラン✓を外して設定開始）後、デスクトップを確認 | `result.csv` がデスクトップに保存・追記されている |
| 10 | ×での削除確認（本適用後） | 本適用・ログ出力後にウィンドウ右上の × を押す | 削除確認ダイアログが表示される（「はい/いいえ/キャンセル」） |
| 11 | ドライランのみの終了 | ドライランのみ実行し × を押す | 削除確認は出ず、通常どおり終了する |
| 12 | 自己アンインストール | #10で「はい」→ログ削除は任意選択 | ツールが端末から削除される（`/opt/ipset`・アイコン・sudoers）。ログは選択に従う |

> #12 は端末からツールを実際に削除します。検証機で試す場合は削除後に
> `bash build.sh` → `sudo bash setup_desktop.sh` で再導入してください。

### C. 異常系の確認（品質確認・任意）
- [ ] 存在しないifnameを含むconfigで実行 → 当該ポートのみ NG、他はOK（隔離）
- [ ] 不正IPを含む行 → 当該行のみ NG・ログ記録、処理継続
- [ ] ケーブル未接続ポート → 設定は入るが状態に応じ判定（運用で確認）
