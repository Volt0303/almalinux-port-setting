# 6ポートLAN IP設定ツール　インストール手順書

**新しいPCに、このツールを初めて導入するための手順書です。**

対象OS: AlmaLinux 9.7 / 9.8
所要時間: 約15〜30分（ポート確認の時間を含む）

---

## この手順書の使い方

- 上から順番に、**1つずつ**実行してください。
- 灰色の枠内の文字は、**そのままコピーして貼り付け**て実行するコマンドです。
- 各手順の最後に **✅確認ポイント** があります。ここが合っていれば次へ進んでください。
- うまくいかない場合は、最後の **「困ったときは」** をご覧ください。

---

## 準備するもの

- [ ] 導入するPC（AlmaLinux がインストール済み・モニタ／キーボード／マウス接続済み）
- [ ] ツール一式が入ったUSBメモリ（または社内サーバからコピーできる状態）
- [ ] インターネット接続（日本語フォントの入手に必要）
- [ ] LANケーブル 1本（ポート確認に使用）

---

## 手順0. 端末（ターミナル）を開く

このあとの作業では「端末」という黒い画面を使います。

1. 画面左上の **「アクティビティ」** をクリックします。
2. 検索窓に **`terminal`** と入力します。
3. **「端末」** のアイコンをクリックします。

以降、コマンドはすべてこの画面に貼り付けて **Enterキー** を押します。

> **貼り付け方**: `Ctrl + Shift + V`（通常の `Ctrl + V` ではありません）

---

## 手順1. ツール一式をPCにコピーする

USBメモリをPCに挿し、ファイルマネージャで
**`PortSetting` フォルダごと**、ホームフォルダ（`/home/ユーザー名/`）へコピーします。

コピーが終わったら、端末で下記を実行して場所を確認します。

```
cd ~/PortSetting/almalinux-port-setting
ls
```

**✅確認ポイント**
`ipset`、`config`、`docs`、`build.sh`、`setup_desktop.sh` などが表示されればOKです。

> フォルダ名が違う場合は、`cd` のあとを実際のフォルダ名に置き換えてください。

---

## 手順2. 日本語フォントを入れる

これを入れないと、画面の日本語が **□□□** と文字化けします。**必ず実行してください。**

```
sudo dnf install -y google-noto-sans-cjk-jp-fonts
```

パスワードを聞かれたら、ログイン時のパスワードを入力します
（入力しても画面に文字は表示されませんが、正しく入力されています）。

**✅確認ポイント**
最後に `完了しました!` と表示されればOKです。
（すでに導入済みの場合は「インストール済み」と出ます。それでOKです。）

---

## 手順3. LANポートの並びを確認する

**この手順が最も重要です。** PCの機種によってポートの呼び名が違うため、
「背面のどのジャックが LAN1 なのか」を確認して記録します。

### 3-1. ポートの一覧を表示する

```
python3 tools/inventory.py
```

`IFNAME` の列に、6つの名前が表示されます（例: `enp1s0f0`、`enp2s0` など）。

**✅確認ポイント**
最後に `Found 6 physical port(s).` と表示されればOKです。
**6個未満の場合**は、LANカードがしっかり挿さっていない可能性があります
（→「困ったときは」参照）。

### 3-2. どのジャックがどの名前かを調べる

端末で下記を実行すると、**ケーブルが挿さっているポートを表示し続けます**。

```
watch -n1 'for d in /sys/class/net/*/device; do n=$(basename $(dirname $d)); printf "%-12s %s\n" $n $(cat /sys/class/net/$n/carrier 2>/dev/null); done'
```

- **`1`** = ケーブルが挿さっている
- **`0`** = 挿さっていない

この状態で、**LANケーブルを背面のジャックに1本ずつ挿し替え**ます。
挿したときに `1` に変わった名前が、そのジャックの名前です。

下の表に書き込んでいってください。

| 背面の表示 | 表示された名前（例） |
|---|---|
| LAN1 | |
| LAN2 | |
| LAN3 | |
| LAN4 | |
| LAN5 | |
| LAN6 | |

終わったら **`Ctrl + C`** で表示を止めます。

> **ヒント**: Intel製のポート（`enp1s0f0`〜`f3` のような名前）では、
> 下記を実行するとそのポートのランプが10秒間点滅するので、より簡単に特定できます。
> ```
> sudo ethtool -p enp1s0f0 10
> ```
> `Operation not supported` と出る場合は、この方法は使えません。上のケーブル法で確認してください。

## 手順4. ポート対応表（設定ファイル）を作る

手順3で調べた並びを、設定ファイルに書きます。

まず、下記を実行してファイルを開きます。

```
gedit config/config_new.ini
```

> `gedit: コマンドが見つかりません` と出た場合は、代わりに下記を実行してください。
> ```
> gnome-text-editor config/config_new.ini
> ```
> どちらも使えない場合は、`nano config/config_new.ini` で開けます
> （保存は `Ctrl + O` → `Enter`、終了は `Ctrl + X`）。

開いた画面に、下記を**貼り付け**ます。

```
[board]
name = MY-BOARD
description = 導入日 2026-08-13

[port_map]
LAN1 = ここに手順3で調べたLAN1の名前
LAN2 = ここに手順3で調べたLAN2の名前
LAN3 = ここに手順3で調べたLAN3の名前
LAN4 = ここに手順3で調べたLAN4の名前
LAN5 = ここに手順3で調べたLAN5の名前
LAN6 = ここに手順3で調べたLAN6の名前
```

「ここに〜の名前」の部分を、手順3の表の内容に**書き換え**てください。

記入例:
```
[port_map]
LAN1 = enp3s0
LAN2 = enp2s0
LAN3 = enp1s0f3
LAN4 = enp1s0f2
LAN5 = enp1s0f1
LAN6 = enp1s0f0
```

書けたら **保存**（`Ctrl + S`）して、画面を閉じます。

**✅確認ポイント**

```
python3 -c "
from ipset.core import detect
for m in detect.evaluate_configs('config'):
    print('%-28s %d/%d 一致  未検出=%s' % (m.path, m.matched, m.total, m.missing or 'なし'))
"
```

作成したファイルが **`6/6 一致`／`未検出=なし`** と表示されればOKです。
`未検出` に名前が出ている場合は、その名前の書き間違いです。手順4をやり直してください。

> **すでに同じ機種用のファイルがある場合**（`config_amd.ini` など）は、
> この手順は不要です。既存のファイルが `6/6 一致` ならそのまま使えます。

---

## 手順5. ツールを組み立てる（ビルド）

```
bash build.sh
```

数分かかります。途中で大量の文字が流れますが、正常です。

**✅確認ポイント**
最後に `>> done. Artifacts in ./dist` と表示されればOKです。

続けて、設定ファイルが含まれているか確認します。

```
ls dist/config/
```

手順4で作ったファイル（`config_new.ini` など）が表示されればOKです。

---

## 手順6. PCにインストールする

```
sudo bash setup_desktop.sh
```

**✅確認ポイント**
`>> Setup complete.` と表示されればOKです。

これで、アプリの一覧に **「LAN IP設定ツール」** が登録されました。

---

## 手順7. 起動して確認する

1. 画面左上の **「アクティビティ」** をクリック
2. 検索窓に **`LAN`** と入力
3. **「LAN IP設定ツール」** のアイコンをクリック

**✅確認ポイント**

- ツールの画面が開く
- 日本語が正しく表示されている（**□□□** になっていない）
- 画面下部に **「ボード自動判別: （ファイル名）… 6 ポート一致」** と表示される

ここまで表示されれば、**インストール完了**です。

---

## 手順8. 試しに動かしてみる（変更されないので安全）

1. **［参照...］** をクリックし、設定用のCSVファイルを選びます。
2. **対象シリアル** 欄に、シリアル番号の一部を入力します（候補が表示されます）。
   表示された候補をクリックして選びます。
3. **「ドライラン（変更しない）」にチェックが入ったまま**、［設定開始］を押します。

**✅確認ポイント**
「設定結果」欄に LAN1〜LAN6 の行が表示され、
画面下部に **「ドライラン完了（変更なし）。」** と出ればOKです。

> この操作では**設定は変更されません**。安心して実行できます。
> 実際に設定するときは、チェックを外して［設定開始］を押します。

## 困ったときは

| 症状 | 原因 | 対処 |
|---|---|---|
| 画面の日本語が **□□□** になる | 日本語フォント未導入 | 手順2をやり直す |
| アイコンをクリックしても開かない | 権限や表示の問題 | 端末で `cat /tmp/ipset-gui.log` を実行し、内容を担当者へ連絡 |
| 「ボード自動判別: 該当なし」と出る | 設定ファイルが実機と合っていない | 手順3・4をやり直す（名前の書き間違いが最多） |
| ポートが6個表示されない | LANカードの挿し込み不良 | PCの電源を切り、増設LANカードを挿し直す |
| `sudo` でパスワードが通らない | 管理者権限がない | 管理者アカウントでログインし直す |
| `command not found` と出る | フォルダの場所が違う | `cd ~/PortSetting/almalinux-port-setting` を実行してから、もう一度 |
| アイコンから起動すると動作が古い | 導入版が更新されていない | `bash build.sh` → `sudo bash setup_desktop.sh` を再実行 |

上記で解決しない場合は、**実行したコマンドと表示された文字をそのままコピーして**
担当者へご連絡ください。

## 2台目以降のPCへ導入する場合

**同じ機種**のPCであれば、手順3・4（ポート確認と設定ファイル作成）は**不要**です。
1台目で作った設定ファイルがそのまま使えます。

1. 手順1（コピー）
2. 手順2（フォント）
3. 手順5（ビルド）
4. 手順6（インストール）
5. 手順7（起動確認）

**別の機種**のPCの場合は、手順3・4も実施してください
（ポートの呼び名が機種ごとに異なるため）。
